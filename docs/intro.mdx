The protocol enables TCP token holders to stake their tokens and earn rewards while maintaining complete transparency and security.

## Key Features

### On-Chain Staking

TCP Protocol features a fully on-chain staking system powered by TCPStakingV2. Token holders can stake their TCP tokens to earn rewards, with no lock-up periods and flexible claiming.

- **Flexible participation**: Stake and unstake anytime
- **Continuous rewards**: Automatic reward accrual per block
- **Transparent accounting**: All operations on-chain and verifiable
- **Secure design**: Multiple layers of protection against overflow and double-payment

### Modular Architecture

The protocol is built with a modular design that separates concerns and enables independent upgrades.

- **TCP Token**: Core ERC-20 token
- **Staking Contract**: Reward distribution and management
- **Treasury**: Timelock-protected asset management
- **Liquidity Manager**: Advanced liquidity handling
- **Router**: Protocol integration hub

### Governance

Protocol governance is managed through a multisig structure with timelock protection, ensuring security and transparency.

- **Multisig control**: Multiple signers required for critical operations
- **Timelock protection**: Delays on sensitive operations
- **Transparent operations**: All governance on-chain
- **Community oversight**: Full visibility into protocol changes

### Security

The protocol implements multiple layers of security to protect user funds and maintain system integrity.

- **Access controls**: Role-based permission system
- **Timelocks**: Delays on critical operations
- **Overflow protection**: Prevents reward pool overflow
- **Double-payment prevention**: Ensures accurate reward distribution
- **Balance verification**: Continuous accounting validation
